# 训练计划

个人 AI 健身教练的 PWA。深色系活力 UI、AI 全程陪伴、纯前端不依赖后端。

**线上访问**:https://iyoumega.github.io/workout/

**手机上**:Safari 打开 → 分享 → 添加到主屏幕,即可像 App 一样使用。
首次添加后,日常使用也可以**离线打开**(AI 功能仍需联网)。

---

## 主要特性

- **AI 教练**有名字、有语气(亲和 / 严师 / 俏皮 / 温柔),全程陪伴
- **聊天 + 快捷动作**:对教练说"今天累",AI 回复后会直接出现"把今天改为休息日"按钮
- **专注训练模式**:逐组引导、自动倒计时、语音报数、节拍器、PR 检测+撒花
- **97 个动作**,健身房 / 哑铃家 / 纯徒手三种场地;支持自定义动作和动作替换
- **建议重量**基于体重 × 经验等级,训练时自动预填;**进阶提示**根据上次成绩推荐这次该加/减
- **时间预算训练**:"今天只有 20 分钟",自动压缩计划
- **每日金句** + **训练第 N 天** 计数器
- **心情打卡**:5 种心情或自由打字,AI 给个性化建议
- **本周日记**:AI 写一篇 300-500 字叙事体周报
- **体重追踪 + 目标 + ETA**、**13 周热力图**、**8 周训练量曲线**、**14 天心情轨迹**
- **PR 检测 + 1RM 估算**、12 项成就 + 解锁动画
- **AI 体态分析**(qwen-vl-max 看体态照片给建议)
- **训练完成 AI 寄语 + 分享卡片**
- **离线 PWA**:Service Worker 缓存,无网可打开

## 自定义

- **设置 → 教练**:改名字 / 语气
- **设置 → 通知与反馈 → 安静模式**:公共场合一键静音
- **设置 → 单位 / 起始日**

## 技术

- 纯静态:HTML + CSS + 原生 JS
- AI:通过 Cloudflare Worker 反代 DeepSeek + Qwen
- 存储:localStorage(可导出 / 导入 JSON 备份)
- PWA:Service Worker + Web App Manifest
